# SENAI Connect

Rede social acadêmica desenvolvida com o objetivo de aproximar alunos, professores, colaboradores e a comunidade do SENAI, criando um ambiente para conexão, compartilhamento de conhecimento, divulgação de projetos e desenvolvimento profissional.

## 📖 Origem do projeto

O SENAI Connect surgiu a partir do projeto **ConexãoPro**, desenvolvido inicialmente como um projeto individual durante o curso de Front-End do SENAI.

A proposta original era criar uma rede social acadêmica capaz de aproximar alunos, professores e colaboradores, permitindo compartilhar projetos, criar conexões e aumentar o engajamento dos estudantes com o ambiente educacional.

O desenvolvimento individual evoluiu por diversas versões até a **versão 9.2 do ConexãoPro**.

Essa versão foi utilizada como base para a etapa seguinte do trabalho, realizada de forma colaborativa pela turma.

## 🚀 Evolução para SENAI Connect

A partir da versão 9.2 do ConexãoPro, o projeto passou por uma nova etapa de desenvolvimento em equipe.

Durante essa fase, diferentes integrantes trabalharam em funcionalidades e páginas específicas, que posteriormente foram integradas em uma versão única.

Também ocorreram mudanças na identidade do projeto, incluindo a adoção do nome:

**SENAI Connect**

A versão presente neste repositório representa a integração dessa evolução coletiva com a base originalmente desenvolvida no ConexãoPro.

## 🤝 Desenvolvimento colaborativo

A versão final foi construída de forma colaborativa durante o curso de Front-End do SENAI.

O projeto **ConexãoPro 9.2** serviu como base para o desenvolvimento coletivo. A partir dela, novas funcionalidades, páginas e melhorias foram produzidas e integradas pelos integrantes da equipe.

Este repositório mantém essa evolução registrada para preservar tanto a origem do projeto quanto o resultado do trabalho realizado em grupo.

## 🎯 Objetivo

Mais do que uma atividade acadêmica, a proposta do projeto é explorar como uma rede social voltada ao ambiente educacional pode contribuir para:

- aumentar a interação entre alunos;
- divulgar projetos desenvolvidos durante os cursos;
- facilitar a descoberta de cursos e oportunidades;
- aproximar alunos, professores e profissionais;
- estimular a criação de portfólio;
- fortalecer o sentimento de comunidade;
- incentivar o desenvolvimento profissional.
